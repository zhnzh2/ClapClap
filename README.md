# ClapClap 1.0 双人对战版

这是一个基于 Python 编写的 **拍拍（ClapClap）1.0 双人对战命令行版本**。  
当前版本的目标是先实现并验证双人同步出招规则，使核心结算逻辑稳定、清晰，并为后续网页版、AI 对战版和联机版打下基础。

## 2. 当前规则约定

当前版本采用以下实现约定：

- 双方都非法动作：双败
- 烈焰优先消耗火种，否则消耗 4 盾
- Shining 优先消耗电池，否则消耗 6 盾
- 第一版中：
  - 黑洞不拆分
  - Shining 不拆分
  - 双吃不拆分
- 闪：完全跳过本回合的一切效果，不能被攻击，也不攻击
- gi 抢镐：只在对方本回合出镐时触发
- 镐在持有时抵挡伤害，而不是“使用镐当回合直接免伤”

## 4. 项目结构

```text
ClapClap/
├─ constants.py
├─ models.py
├─ game.py
├─ main.py
├─ README.md
└─ tests/
   ├─ __init__.py
   └─ test_logic.py
```

各文件功能如下：

- constants.py
    - 定义资源、动作、消耗、攻击力、防御力、伤害值等常量表。
- models.py
    - 定义玩家状态、游戏状态、回合日志等数据结构。
- game.py
    - 实现核心规则结算逻辑，包括资源检查、消耗、攻击防御、锦囊特判、镐结算、胜负判定等。
- main.py
    - 提供命令行双人对战入口，用于手动测试和体验当前版本。
- tests/test_logic.py
    - 提供单元测试，验证核心规则的正确性。
