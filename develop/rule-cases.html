1
普通单目标攻击
层7攻击
输入
3 人局。A 出冷锋(攻3)，B 出气(防0)，C 出盾(防1.5)。层 7，A 选择攻击 B。
过程
层 7：A 攻3 > B 防0 → 攻击成立。A 造成 1 点伤害，A 防御归零，A、B 变为已操作对象。C 在本层无操作。
结果
B 生命值 -1（若初始 1 → 变为 0）。层 12 B 仍可获得盾（被动资源）。回合末 B 生命值 ≤ 0 → 死亡。
涉及层：7(冷锋) → 12(气/盾)
2
同攻击力互相攻击（对掉）
冲突攻击
输入
2 人局。A 出破(攻2)，B 出破(攻2)。层 9，A 意向攻击 B，B 意向攻击 A。
过程
同速冲突（互指）。攻2 = 攻2 → 对掉。双方攻击互相抵消，不造成伤害。
结果
双方变为已操作对象。对掉的攻击已成立（双方都选择了攻击），因此都防御归零、都变已操作。0 伤害。
规则依据：规则书 §4.2 — "当双方攻击力相等，且彼此互相攻击时，双方视为对掉"
3
攻击防御手势但未打穿
攻击
输入
2 人局。A 出 gi(攻1)，B 出八卦(防4)。层 8，gi 必须选目标，合法目标只有 B。
过程
gi 攻1 < 八卦防4 → 攻击不成立，不造成伤害。但攻击行为本身已发生（gi 不能放空），交互成立。
结果
A 变为已操作对象（发动了攻击），A 防御归零。B 变为已操作对象（被攻击）。B 防御力不受影响。
关键：即使未打穿，双方仍变已操作。规则书 §5.1："成功攻击别人并不需要造成伤害"。
4
攻击者防御归零
冲突攻击
输入
3 人局。A 出冷锋(攻3)，B 出冷锋(攻3)，C 出气(防0)。层 7。
过程
A 选择攻击 C → A 防御归零（攻3 → 防0）。B 选择攻击 A → B 攻3 > A 防0 → 攻击成立。
这是典型的"强杀"场景。
结果
A 攻击 C：攻3 > 防0 → 成立，C 受 1 点伤害。A、C 已操作。
B 攻击 A：攻3 > 防0 → 成立，A 再受 1 点伤害。B 已操作。
A 承受两次攻击后果（对 C 的攻击成立 + 被 B 的伤害打中）。
同速层内：同时发出、命中、扣血。若有人因此死亡，同时死亡。
5
gi 无合法目标
gi
输入
2 人局。A 出 gi，B 也出 gi。gi 不能攻击 gi → A 无合法目标，B 也无合法目标。
过程
层 8：双方 gi 都没有合法目标 → 不在层 8 结算。层 11（无目标 gi）：双方 gi 均失效。
结果
A、B 均保持未操作对象。gi 消耗的 1 气不退还。
回合只有资源手势结算（若有人出气/盾等）。
注意：2 人局双方都出 gi 会导致对局无法推进，除非有人换手势。
6
gi 强制攻击
gi
输入
3 人局。A 出 gi，B 出气(防0)，C 出 gi。A 的合法目标：仅 B（C 是 gi 不能攻）。
过程
存在合法目标 B → gi 必须攻击，不能放空。层 8：A 选择 B 为目标。
结果
gi 攻1 > 气防0 → 攻击成立。B 受 1 点伤害。A 已操作，B 已操作。
规则依据：规则书 §5.5.3 — "若 gi 存在任何可攻击目标，则 gi 不能放空，必须选择攻击"
7
gi 攻击黑洞（反噬）
层4gi
输入
2 人局。A 出 gi，B 出黑洞(攻5)。
过程
层 4（gi 攻击黑洞）：A 的 gi 选择 B 的黑洞为目标。gi 攻1 < 黑洞防5，但 gi 攻击黑洞是特殊规则 → 成立。
B 受 3 点反噬伤害。A、B 变已操作对象。
层 5（黑洞）：B 已操作 → 不能选择目标拆分，黑洞作废。
结果
B 生命值 -3。A 消耗 1 气。B 消耗 8 气（黑洞消耗不退）。回合末 B 若 HP ≤ 0 → 死亡。
关键：黑洞在层 5 已操作 → 不能再拆分，拆分作废。
8
gi 抢镐
层8gi
输入
2 人局。A 出 gi，B 出加镐。A 没有镐，B 也没有镐。
过程
层 8（gi 抢镐）：A 选择 B 为目标，选择"抢镐"操作。
加镐防0 < gi攻1 → 抢镐成立。
A 获得 1 个镐。A、B 变已操作对象。
层 12（加镐）：B 已是已操作对象且被抢镐 → 不获得镐。
结果
A：镐 1。B：镐 0（被抢）。A 消耗 1 气，B 消耗的资源（若有）不退。
同一 gi 二选一：A 只能选择抢镐（不能同时造成伤害）。
9
你吃 → 破
层3锦囊
输入
2 人局。A 出你吃，B 出破(攻2)。
过程
层 3（你吃）：A 选择 B 为目标。B 出破 → 你吃生效。
B 的破直接失效，B 受到 1 点反噬伤害。A、B 变已操作对象。
层 9（破）：B 已操作 → 不能攻击。
结果
A 消耗 1 气。B 破作废（消耗 2 气不退）+ 受 1 点反噬伤害。
规则依据：规则书 §5.4.1
10
你吃 → 闪电
层3锦囊
输入
2 人局。A 出你吃，B 出闪电(攻2)。
过程
层 3（你吃）：A 选择 B。B 出闪电 → 你吃生效。
闪电直接失效，B 不获得电池。A、B 变已操作对象。
结果
A 消耗 1 气。B 闪电作废（消耗 3 盾不退），不获得电池。
11
双吃 → Shining
层3锦囊
输入
2 人局。A 出双吃，B 出 Shining(攻4)。
过程
层 3（双吃）：A 选择 B。B 出 Shining → 双吃对 Shining 生效。
Shining 攻击直接失效。A、B 变已操作对象。
层 6（Shining）：B 已操作 → 不能拆分。
结果
A 消耗 2 气。B Shining 作废（消耗 6 盾不退）。
12
双吃拆分
层3锦囊拆分
输入
3 人局。A 出双吃，B 出破，C 出闪电。
过程
层 3：A 拆分双吃为两个你吃 → 你吃₁ 选择 B(破)，你吃₂ 选择 C(闪电)。
两个你吃各自独立结算。
你吃₁ 对 B：破失效，B 受 1 点反噬。B 已操作。
你吃₂ 对 C：闪电失效，C 不获电池。C 已操作。
A 已操作。
结果
A 消耗 2 气。B 破作废 + 1 反噬伤害。C 闪电作废 + 不获电池。层 9 的 B(破)、C(闪电) 均因已操作无法再打击。
13
Shining 拆分
层6→9拆分
输入
3 人局。A 出 Shining，B 出气(防0)，C 出盾(防1.5)。
过程
层 6：A 声明拆分 → 闪电₁ 目标 B，闪电₂ 目标 C。
层 9（破/闪电）：两个拆分闪电在此时结算。
闪电₁ 对 B：攻2 > 防0 → 攻击成立，B 受 1 点伤害。A 获得电池₁。
闪电₂ 对 C：攻2 > 防1.5 → 攻击成立，C 受 1 点伤害。A 获得电池₂。
结果
A 获得 2 个电池。B 生命值 -1。C 生命值 -1。A、B、C 全部变为已操作。
关键：拆分声明在层 6，但实际结算在层 9（按闪电的速度）。
14
黑洞拆分
层5拆分
输入
4 人局。A 出黑洞(攻5)，B 出气(防0)，C 出盾(防1.5)，D 出破(攻2)。
过程
层 5：A 拆分 3 个小黑洞。
黑洞₁ → B（气，防0）：攻5 > 防0 → 成立，B 受 1 伤害。
黑洞₂ → C（盾，防1.5）：攻5 > 防1.5 → 成立，C 受 1 伤害。
黑洞₃ → B：可重复打同一目标，B 再受 1 伤害。
三个小黑洞同时结算。
结果
B 生命值 -2（两段命中）。C 生命值 -1。A、B、C 变已操作。D 仍未操作，层 9 可正常出击。
15
三连 (1,1,1)
层2三连
输入
3 人局。A 出 gi，B 出黑洞(攻5)，C 出破(攻2)。类型二：gi → 黑洞 → 其它攻击(破) → gi。
过程
层 2（三连检测）：A(gi)、B(黑洞)、C(破) 满足三连（只看手势类型克制链）。
三连成立 → 三人攻击全部无效，全部变为已操作对象。
结果
A、B、C 全部已操作。后续速度层中三人均不能攻击/被攻击/被锦囊作用。
资源手势仍正常（层 12 气/盾等）。
16
三连 (1,1,多) 与 (1,多,多)
层2三连
场景A
(1,1,多)：A(gi)，B(黑洞)，C(破)，D(破)。gi→黑洞→破→gi。破方有 2 人。
克制多人方（破）的是 gi 方 → A 从 C、D 中选择一人，与 B 组成三连。
A 选 C → A、B、C 三连成立，全部已操作。D 未参与三连，仍可继续。
场景B
(1,多,多)：A(gi)，B(黑洞)，C(黑洞)，D(破)，E(破)。gi 方 1 人。
第一步：A 从自己克制的两黑洞 B、C 中选一人 → 选 B。
第二步：B 从自己克制的两破 D、E 中选一人 → 选 D。
A、B、D 三连成立。C、E 未参与三连。
选择超时：当前阶段默认不超时。后续阶段引入 30s 超时 + 随机。
17
两组三连（六人）
层2三连
输入
6 人局。A/B/C 形成独立三连，D/E/F 形成另一组独立三连。
过程
层 2：检测到两组独立三连（6 人）→ 本回合直接结束。
6 人全部变为已操作对象。仅资源手势和加镐仍正常结算。
结果
所有攻击和锦囊均无效（无论是否在三连中）。层 12 的气/盾/加镐正常获得。
回合末正常判定死亡。
规则依据：规则书 §6.2.2 — "本回合直接结束，除资源手势与加镐仍正常结算外，其余攻击和锦囊均无效"
18
多人攻击同一目标（多攻击少）
协商攻击
输入
3 人局。层 9，A 出破(攻2)，B 出破(攻2)，C 出气(防0)。A 和 B 都想攻击 C。
过程
同速冲突 — 多攻击少。A 意向→C，B 意向→C。
后端通知 C："A 和 B 都想攻击你，请选择由谁来攻击你"。
C 选择 A → A 攻击 C 成立，B 放空。A、C 变已操作。B 保持未操作（放空）。
结果
C 承受来自 A 的 1 点伤害。A 防御归零。B 不造成伤害，保留防御力（放空）。
规则依据：规则书 §6.4.2 — "由被攻击方决定由谁来攻击自己"
19
同速强杀
协商攻击
输入
3 人局。层 9，A 出破(攻2)，B 出破(攻2)，C 出气(防0)。
A 意向攻击 C，B 意向攻击 A。
过程
此为一般冲突（非多攻击少，目标不重叠）。A→C，B→A，互不重叠。
经检测，无冲突（目标不冲突，不互相干扰）→ 同时结算。
A 攻击 C → 攻2 > 防0，成立，C 受 1 伤害。但 A 在攻击打出瞬间防御归零。
B 攻击 A → 此时 A 防已归零，攻2 > 防0，成立，A 受 1 伤害。
结果
A 同时是攻击者和被攻击者。A 对 C 造成 1 伤害 + 自己被 B 打 1 伤害。
同速层内同时命中、同时扣血 → 若 A 和 C 都因本层 HP≤0，同时死亡。
20
快速层已操作 → 慢速层的影响
攻击
输入
2 人局。A 出黑洞(攻5) + 破(不可能，一人只能出一个手势)...
修正示例：3 人局。A 出你吃，B 出破(攻2)，C 出冷锋(攻3)。
过程
层 3（你吃）：A 你吃→B 的破。你吃生效，B 破失效 + 1 反噬。A、B 已操作。
层 7（冷锋）：C 寻找未操作目标 → 只有 A（已操作）和 B（已操作）→ 无法攻击已操作对象 → C 无合法目标，放空。
层 9（破）：B 已操作 → 不能攻击。
结果
C 的冷锋虽有高攻击力，但因无合法目标只能放空。B 的破因在层 3 被吃而完全作废。
21
已操作玩家仍获得被动资源
攻击
输入
3 人局。A 出 Fire，B 出 gi。层 3 无操作。层 8：B 的 gi 攻击 A。
过程
层 8（gi 攻击）：B(gi)→A(Fire 防1.5)。gi 攻1 < Fire 防1.5 → 攻击不成立（未打穿）。
但攻击行为已发生 → A、B 变为已操作对象。
层 10（Fire）：A 已操作，但仍获得 1 个火种（被动资源，规则书 §6.5 明确允许）。
结果
A：获得 1 火种。B：gi 消耗 1 气，攻击未造成伤害。A 未被扣血。
规则依据：规则书 §6.5 — "即使玩家在轮到其速度级之前就已经成为了已操作对象，其仍然能够获得相应的资源（被吃掉的闪电和被抢镐除外）"
22
同回合多人死亡
死亡
输入
4 人局。层 9，A 破→B(HP=1)，C 破→D(HP=1)。B 和 D 均受 1 点伤害。
过程
层 9 同时结算后：B HP=0，D HP=0。回合末判定：B 和 D 均死亡。
结果
B 和 D 并列第 3 名（4 人参赛，2 人存活 → 名次 1、2、3、3）。
下一回合剩余 A 和 C（2 人）。
23
全员死亡（平局）
死亡
输入
2 人局。层 9，A 破→B(HP=1)，B 破→A(HP=1)。同速同时命中。
过程
同速无冲突（互指 → 对掉？不对，攻2 = 攻2 → 对掉 → 无伤害?）
不是对掉的情况：A 破→B(防0的加镐)，B 破→A(防0的加镐)。攻2 > 防0，都成立。
A 和 B 各受 1 点伤害，HP 均变 0。回合末判定：双方均死亡。
结果
平局。所有参与者并列。存活人数 = 0 → 无人获胜。
24
爆镐（gi 抢镐触发 + 加镐触发）
死亡gi
场景A
gi 抢镐触发爆镐：A 已有 1 个镐（上回合加镐获得）。B 出 gi，A 出加镐。
层 8：B gi 抢镐 → A（加镐）。抢镐成功，B 获得镐。
B 此时已有 1 个镐 + 新抢到 1 个 = 2 个镐 > 上限 1 → 立即爆镐死亡。
B 从层 8 即刻移除，不参与层 9~12。
场景B
加镐触发爆镐：A 已有 1 个镐（包含在被 gi 攻击后 HP ≤ 0 的复活情况…但注意：HP ≤ 0 时是恢复 1 HP 而不是获得镐实体，所以不会爆镐）。
实际触发：A 已有 1 镐，又出加镐且未被 gi 抢镐。层 12 获得第 2 镐 → 立即爆镐死亡。
结果
爆镐死亡在触发速度层立即移除，不参与后续结算。死因记录为"爆镐"。
注意：若 gi 在层 8 攻击已操作对象 → 不能攻击。若加镐者在较早层已被 gi 攻击（变已操作）→ 不能抢镐。
