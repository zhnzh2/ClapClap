按键操作

· 1 / 2 / 3 / 4：选择锦囊动作

· Q / W / E / R：选择资源与防御动作

· A / S / D / F / G：选择气系攻击动作

· Z / X / C / V：选择盾系攻击动作

· Enter：确认当前已选择的动作

· Backspace：取消当前选择；如果你已经提交且对方尚未提交，则撤回本回合提交

· Escape：关闭帮助弹窗、设置弹窗或结束弹窗

大致规则

· 每回合双方各选择一个动作，双方都确认后统一结算。

· 资源动作主要用于获得气、盾等后续行动所需资源。

· 攻击动作会消耗已有资源并对对方造成伤害。

· 防御与锦囊动作会根据规则在不同对局中起到抵挡、转化或特殊效果。

· 任意一方生命值降到 0 或以下时，对局结束。
