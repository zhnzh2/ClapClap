基本操作

1. 准备阶段设定人数（2~6），点击"开始对局"。
2. 为每位玩家选择动作，当前焦点玩家用蓝色边框标识。
3. 点击"提交本回合"后，后端按速度层逐级结算。
4. 如有决策点（选目标/协商），在结算进度卡片中直接操作。
5. 结算完成后查看回合总结，点击"继续下一回合"。

键盘操作

· Tab：切换焦点玩家
· 1/2/3/4：锦囊（你吃/双吃/黑洞/如来）
· Q/W/E/R：资源与防御（气/盾/加镐/十字）
· A/S/D/F/G：气系攻击（gi/破/闪电/冷锋/Shining）
· Z/X/C/V：盾系攻击（烈焰/Fire/闪/八卦）
· Enter 或再次按已选动作快捷键：全部玩家选完后提交本回合
· Backspace：撤销焦点玩家选择 / 关闭弹窗
· 决策区或总结区打开时，Enter 用于确认决策 / 继续
· Escape：关闭帮助弹窗

结算流程

资源检查 → 亮招 → 闪 → 三连 → 速度层 3~12 → 死亡判定 → 回合总结
速度层顺序： 层1 闪、层2 三连、层3 你吃/双吃、层4 gi→黑洞、层5 黑洞、层6 如来/Shining、 层7 冷锋/烈焰、层8 gi攻击/抢镐、层9 破/闪电、层10 Fire、层11 gi无目标、层12 气/盾/加镐
注意：初始资源全为 0。第一回合只能出「气」「盾」「闪」来收集资源， 后续回合才能使用消耗资源的手势。
自动决策：勾选后，所有决策点（目标选择、冲突协商）自动使用默认值， 无需手动操作。适合快速测试和体验规则流程。取消勾选则每个决策点都需要手动选择。
