基本操作

1. 准备阶段设定人数（2~6），点击"开始对局"。
2. 为每位玩家选择动作，当前焦点玩家用蓝色边框标识。
3. 点击"提交本回合"后，后端按速度层逐级结算。
4. 如有决策点（选目标/协商），在页面中直接操作。
5. 结算完成后，点击"继续下一回合"。

键盘操作

· Tab：切换焦点玩家
· 1/2/3/4：锦囊
· Q/W/E/R：资源与防御
· A/S/D/F/G：气系攻击
· Z/X/C/V：盾系攻击
· Enter：提交本回合 / 确认决策 / 继续
· Backspace：撤销焦点玩家选择
· Escape：关闭帮助弹窗

结算流程

资源检查 → 亮招 → 闪 → 三连 → 速度层 3~12 → 死亡判定 → 回合总结
