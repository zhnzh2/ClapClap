帮助

基本操作

1. 在左右两边分别为 P1 和 P2 选择动作。
2. 被选中的动作会高亮显示。
3. 点击“提交本回合”后，后端会统一结算。
4. 点击“重新开始”可以重置游戏。

键盘快捷操作

· 锦囊：1 / 2 / 3 / 4
· 资源与防御：Q / W / E / R
· 气系攻击：A / S / D / F / G
· 盾系攻击：Z / X / C / V
· 默认先给 P1 选，P1 选完自动轮到 P2。
· Enter：双方都选完后提交；若结束弹窗打开，则快速重新开始。
· Backspace：撤销最后一次选择；若有弹窗打开，则关闭所有弹窗。

当前实现约定

· 双方都非法动作：双败。
· 烈焰优先消耗火种，否则消耗 4 盾。
· Shining 优先消耗电池，否则消耗 6 盾。
· 黑洞、Shining、双吃当前版本不拆分。
· 闪会完全退出本回合结算。
· gi 抢镐只在对方本回合出镐时触发。

设置

紧凑模式
